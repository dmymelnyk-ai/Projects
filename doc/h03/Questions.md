# Questions.md

### 1. Навіщо потрібні окремі типи для цілих і дробових чисел?

Цілі числа використовують для значень без дробової частини, а дробові — для значень із дробовою частиною. Це допомагає правильно зберігати й обробляти різні дані.

### 2. Чим відрізняються типи float і double у Java?

Обидва типи зберігають дробові числа, але double має більшу точність. Тому його часто використовують для обчислень із дробовими значеннями.

### 3. Чому дробові числа іноді зберігаються неточно?

Деякі десяткові дроби неможливо точно представити у двійковій системі. Через це під час обчислень можуть виникати невеликі похибки.

### 4. Чому результат обчислення двох дробових чисел може бути не зовсім точним?

Тому що комп'ютер зберігає дробові числа з обмеженою точністю. Під час обчислень ця похибка може проявлятися в результаті.

### 5. Що таке приведення типів?

Приведення типів — це перетворення значення з одного типу даних в інший. Наприклад, у Java можна перетворити int на double.

### 6. Що станеться, якщо перетворити дробове число на int?

Дробова частина буде відкинута. Наприклад, під час перетворення 5.8 на int результатом буде 5.
