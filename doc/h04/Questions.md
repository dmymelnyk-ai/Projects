# Questions.md

### 1. Навіщо в програмуванні окремий тип для «так» і «ні»?

Тип boolean потрібен для зберігання логічних значень true і false. Він використовується для перевірки умов і прийняття рішень у програмі.

### 2. Чим відрізняються оператори && та ||?

Оператор && повертає true, якщо обидві умови істинні. Оператор || повертає true, якщо істинна хоча б одна умова.

### 3. Для чого використовується оператор !?

Оператор ! заперечує логічне значення. Якщо значення true, результат буде false, і навпаки.

### 4. Чим відрізняються логічні оператори від побітових?

Логічні оператори працюють із логічними умовами. Побітові оператори працюють з окремими бітами чисел.

### 5. Для чого потрібна конструкція if?

Конструкція if дає змогу виконувати певний блок коду лише тоді, коли умова істинна.

### 6. Чому важливо правильно складати логічні умови?

Неправильна умова може призвести до того, що програма виконає не ті дії, які потрібні. Тому необхідно перевіряти умови та логіку їх поєднання.
