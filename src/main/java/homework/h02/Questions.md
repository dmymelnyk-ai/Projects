# Questions.md

### 1. Чому комп'ютер рахує двійками, а не десятками, як ми?

Комп'ютер використовує двійкову систему, тому що електронні компоненти зручно представляти двома станами: 0 і 1.

### 2. Що таке біт і байт?

Біт — це найменша одиниця інформації, яка може мати значення 0 або 1. Байт складається з 8 бітів.

### 3. Як комп'ютер зберігає від'ємні цілі числа?

У Java тип int використовує 32 біти. Від'ємні числа зберігаються у двійковому представленні з використанням додаткового коду.

### 4. Що таке переповнення цілого числа?

Переповнення виникає, коли результат обчислення виходить за межі діапазону, який може зберігати певний тип даних.

### 5. Чому найбільше значення типу int у Java дорівнює 2 147 483 647?

Тип int має 32 біти, один з яких використовується для знака. Тому найбільше додатне значення дорівнює 2³¹ − 1, тобто 2 147 483 647.

### 6. Що відбувається під час ділення двох цілих чисел у Java?

Якщо обидва числа цілі, результат ділення також буде цілим. Дробова частина відкидається. Наприклад, 7 / 2 дає 3.
