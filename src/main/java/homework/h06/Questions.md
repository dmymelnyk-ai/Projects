# Практична робота №6. Питання та відповіді

### 1. Як комп’ютер зберігає літери, якщо він працює лише з числами?

Комп’ютер зберігає літери за допомогою числових кодів. Кожному символу відповідає певний код, за яким комп’ютер може визначити, яку літеру потрібно показати.

### 2. Чим відрізняються `'A'` та `"A"` у Java?

`'A'` — це один символ типу `char`, а `"A"` — рядок типу `String`. Хоча вони виглядають однаково, у програмі це різні типи даних.

### 3. Чим відрізняється порожній рядок від відсутнього значення?

Порожній рядок `""` існує, але не містить тексту. Значення `null` означає, що об’єкт не має заданого значення.

### 4. Чому замість правильного тексту іноді з’являються незрозумілі символи?

Таке трапляється, коли текст відкривають із неправильним кодуванням. Комп’ютер неправильно розпізнає символи, тому замість звичайного тексту показує незрозумілі знаки.

### 5. Скільки символів містить емодзі 👨‍👩‍👧?

Для людини це один видимий символ — емодзі сім’ї. Але технічно він складається з кількох символів Unicode, об’єднаних разом.

### 6. Чому текст «Привіт» може займати більше місця у файлі, ніж «Hello»?

Це залежить від кодування тексту. У кодуванні UTF-8 українські літери зазвичай займають більше байтів, ніж англійські літери, тому слово «Привіт» може займати більше місця, ніж «Hello».
