# Практична робота 6 — Questions

### 1. How does computer store a letter if it only stores numbers?

Комп'ютер зберігає літери у вигляді чисел. Кожному символу відповідає певний числовий код, наприклад за стандартом Unicode.

### 2. Why are 'A' and "A" different things?

'A' — це один символ типу char, а "A" — рядок типу String. Рядок може містити один або багато символів.

### 3. Difference between empty string and missing value?

Порожній рядок "" існує, але не містить символів. Відсутнє значення, наприклад null у Java, означає, що об'єкт не заданий.

### 4. Why mojibake appears instead of text?

Mojibake виникає, коли текст читається з неправильним кодуванням. Через це замість правильних символів можуть з'являтися незрозумілі знаки.

### 5. How many letters in 👨‍👩‍👧?

Це емодзі сім'ї, яке для людини виглядає як один символ, але складається з кількох символів Unicode, об'єднаних разом.

### 6. Why does “Привіт” weigh more than “Hello” in a file?

Розмір тексту у файлі залежить від кодування. У UTF-8 кириличні літери зазвичай займають більше байтів, ніж латинські, тому «Привіт» може займати більше місця, ніж «Hello».
