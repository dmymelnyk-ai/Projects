1. Навіщо потрібні окремі типи для цілих і дробових чисел?

Цілі числа використовують для значень без дробової частини, наприклад кількості студентів. Дробові числа потрібні для значень із частиною, наприклад температури або ваги. Для них комп’ютер використовує різні способи зберігання.

2. Що означає «рухома кома» і куди вона рухається?

Рухома кома — це спосіб зберігання дуже великих, дуже малих або дробових чисел. Кома може умовно зміщуватися завдяки степеню числа 10 або 2. Це дає змогу зберігати числа в компактному вигляді.

3. Скільки цифр після коми комп’ютер здатен запам’ятати?

Це залежить від типу даних. Наприклад, у Java тип float має приблизно 6–7 значущих десяткових цифр, а double — приблизно 15–16. Це не означає, що стільки цифр завжди буде після коми: кількість залежить від самого числа.

4. Чому 0.1 + 0.2 не дорівнює 0.3?

Деякі десяткові дроби неможливо точно записати у двійковому форматі з рухомою комою. Тому комп’ютер зберігає їх наближено, і під час додавання може виникнути невелика похибка.

5. Чому гроші ніколи не зберігають у double?

double може зберігати десяткові дроби з невеликою похибкою, що небажано під час фінансових обчислень. Для грошей краще використовувати ціле число найменших грошових одиниць, наприклад копійок або центів, чи спеціальний тип на кшталт BigDecimal у Java.

6. Чи може число не дорівнювати саме собі?

Так. У програмуванні значення NaN («не число») не дорівнює навіть самому собі. Наприклад, у Java вираз Double.NaN == Double.NaN повертає false.
