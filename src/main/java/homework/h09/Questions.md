# Questions

### 1. Навіщо виділяти код в окрему функцію, якщо він і так працює?

Щоб не повторювати один і той самий код кілька разів. Так програму легше читати, змінювати та перевіряти.

### 2. Чим відрізняється параметр від аргументу?

Параметр — це змінна, яка вказується під час створення методу. Аргумент — це конкретне значення, яке передається під час виклику методу.

### 3. Чому функція не бачить усі змінні програми?

Тому що змінні мають свою область видимості. Наприклад, локальна змінна доступна тільки всередині методу або блоку, де її створили.

### 4. Якої довжини має бути функція?

Немає точної кількості рядків. Головне, щоб функція виконувала одну зрозумілу задачу і її було легко читати.

### 5. Чому функція може змінити переданий масив?

У Java передається копія посилання на масив. Але вона вказує на той самий масив, тому зміни його елементів видно і за межами методу.

### 6. Що повертати, якщо нічого не знайдено?

Це залежить від задачі. Наприклад, можна повернути -1, якщо шукаємо індекс, false для логічної перевірки або порожній список, якщо шукаємо елементи.
