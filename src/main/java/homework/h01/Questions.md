# Questions.md

### 1. Чим програма відрізняється від алгоритму?

Алгоритм — це послідовність кроків для розв'язання задачі. Програма — це алгоритм, записаний мовою програмування, щоб комп'ютер міг його виконати.

### 2. Чому один алгоритм можна написати різними мовами програмування?

Тому що різні мови програмування можуть використовуватися для опису однакових дій. Наприклад, один алгоритм можна реалізувати на C++, Java або Python.

### 3. Чому програма може працювати не так, як ми очікуємо?

Причиною можуть бути помилки в коді, неправильні умови або неправильні вхідні дані.

### 4. Чи можна вважати рецепт борщу алгоритмом?

Так, тому що рецепт містить послідовність дій, які потрібно виконати в певному порядку, щоб отримати результат.

### 5. Чому важливо дотримуватися послідовності дій в алгоритмі?

Тому що зміна порядку може вплинути на результат. Наприклад, деякі дії потрібно виконати до інших.

### 6. Навіщо тестувати програму після написання?

Тестування допомагає перевірити, чи правильно працює програма, і знайти помилки.
